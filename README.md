## Overview
React Calculator Builder is an interactive web application that allows users to create custom calculators through a drag-and-drop interface. Users can dynamically add, remove, and position calculator components while seeing real-time calculation results.

## Features:-

### Core Functionality
- 🧮 Dynamic calculator component creation
- 🖱️ Drag-and-drop interface using react-dnd
- 🔢 Real-time calculation updates
- ❌ Component removal with hover delete buttons
- ↩️ Undo/Redo functionality
- 💾 Automatic state persistence using local storage

### UI/UX Features
- 🌓 Dark/Light mode toggle
- 📱 Responsive design for all screen sizes
- 🎯 Grid-snapping for precise component placement
- 💫 Smooth animations and transitions
- 👆 Touch device support

## Technologies Used
- React.js
- React DnD (Drag and Drop)
- Zustand (State Management)
- Tailwind CSS
- UUID
